🔹 2. ObjectId ka structure (yeh main reason hai 🔥)

| 4 bytes | 5 bytes        | 3 bytes |
| time    | machine+process| counter |

ObjectId = 12 bytes (24 hex characters)

  🔍 Detail:
Timestamp (4 bytes)
→ kab document create hua
→ isse sorting fast ho jati hai
Machine + Process ID (5 bytes)
→ kis system se generate hua
→ distributed systems me unique banata hai
Counter (3 bytes)
→ auto-increment type value
→ same second me bhi unique

The below example illustrates the basic functionality of the Mongoose Connection lean() method. In this example, we can easily differentiate that the result set is the instance of the JavaScript object and is not an instance of the mongoose Document class.















Why Use .lean() in Mongoose?
Here are the key reasons to use lean() in Mongoose:

Performance Optimization: Returning plain JavaScript objects instead of full Mongoose document objects reduces the overhead. This can lead to faster queries and reduced memory usage, especially in read-heavy applications.
No Extra Mongoose Functionality: If you don't need Mongoose document features like instance methods, virtuals, or hooks, using .lean() is beneficial as it provides a cleaner, faster result.
Simple Data Structure: Sometimes, working with plain objects is all you need, especially when you're not updating or modifying the data.
