Virtuals are fake fields on Mongoose documents that are computed from real data and are not stored in MongoDB.

Agar chaho to main tumhe virtual vs methods vs statics bhi compare karke samjha deta hoon.

Mongoose me virtuals aisi properties hoti hain jo MongoDB me store nahi hoti, but document ke saath calculated field ki tarah kaam karti hain.



import mongoose from "mongoose";

const userSchema = new mongoose.Schema({
  firstName: String,
  lastName: String
});

userSchema.virtual("fullName").get(function () {
  return `${this.firstName} ${this.lastName}`;
});

const User = mongoose.model("User", userSchema);



const user = new User({
  firstName: "Tanish",
  lastName: "Tandon"
});

console.log(user.fullName);


Tanish Tandon







Document middleware runs on a single document instance, not on queries.

👉 It triggers when you call methods like:

doc.save()
doc.validate()
doc.remove() (deprecated → use deleteOne)











👉 Query middleware runs when you execute queries on the model, not on a single document.

User.find()
User.findOne()
User.updateOne()
User.deleteOne()








👉 Model middleware runs on Model-level methods (not document, not query).
User.insertMany()
User.createCollection()


Method	Use
insertMany()	bulk insert
createCollection()	create DB collection
bulkWrite()	multiple operations


Type	Runs On	this
Document	doc.save()	document
Query	Model.find()	query
Model	Model.insertMany()	model
