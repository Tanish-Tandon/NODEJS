🔹 Step 3: Real life example (IMPORTANT 🔥)

Situation:


Tum dono ne same data dekha:


{ name: "Tanish", __v: 0 }


Tumne update kiya:


{ name: "Tanish A", __v: 1 }


Tumhara friend (old version ke sath) update karta hai



🔴 Problem kya hai?
Friend ke paas old data hai (__v = 0)
👉 DB me latest hai (__v = 1)

🔥 Yahan __v ka kaam aata hai
Mongoose check karta hai:
Tum update kar rahe ho version 0 seBut DB me already version 1 hai
👉 ❌ Update reject

🔹 Simple line me samajh:

__v = "tum jis data ko update kar rahe ho wo latest hai ya purana?"

Friend ka update tumhara data overwrite kar deta


Tumhara change lost ho jata


👉 data loss 💥

import mongoose ,{Schema} from "mongoose";

const userSchema=new Schema({
    name:{
        type:String,
        required:[true,"Name is required Please provide name"],
        minLength:[5,"Name must be at least 5 characters long"],

    },
    age:{
        type:Number,
        required:[true,"Age is required Please provide age"],
        min:[18,"Age must be at least 18"],
    },

     email:{
        type:String,
        required:[true,"Email is required Please provide email"],
        match:[/^\w+([\.-]?\w+)*@\w+([\.-]?\w+)*(\.\w{2,3})+$/,"Please provide a valid email address"],
    },

    hobby:[String]
},

{
    strict:"throw",// jo schema mai nhi hai wo data insert nh hoga aur error throw hoga



    timestamps:true,// createdAt and updatedAt fields automatically add kr dega mongoose
});










const UserModel=mongoose.model("User",userSchema);

Thenable object = koi bhi object jisme .then() method hota hai

    resolve("Hello bhai");

  console.log(data); // Hello bhai
});
